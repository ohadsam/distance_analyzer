# Fully native Kotlin apps (Special Events, Smart Alarm Clock, Tehilim_Daily, ExtendedFileManager)

Use when the app is native by nature. The detailed proven method is the **`android-native-dev` skill in `ohadsam/special_events`** (`.claude/skills/android-native-dev/`, with `templates/` for `android-ci.yml`, `latest-apk.yml`, `release.yml`, `ui-tests.yml`, detekt/ktlint config, `libs.versions.toml`). Summary:
* Kotlin + Compose + Material 3, single `:app`, package-by-feature, manual DI (`AppContainer`) or Hilt (Smart Alarm uses Hilt), Room (+ explicit `Migration` per schema bump, never destructive in release), DataStore, WorkManager + AlarmManager for exact user-visible times, OkHttp + kotlinx.serialization, Glance widgets.
* Docs: `CLAUDE.md` (<= ~60 lines), `docs/PLAN.md` (batch table), `docs/SPEC.md`, `AGENT.md` (recently done / open items / not verifiable), `STRUCTURE.md` code map, `docs/SECURITY.md` when permissions/exports/files change, in-app help topics kept current.
* Workflow: one batch at a time; never start a batch on red CI; versionCode = `100 + commit count`; `latest-apk.yml` compares the new APK with the published one (applicationId, signing cert, versionCode) and fails on any difference.
* Smart Alarm Clock extras: "share the app" (APK + install text via FileProvider; `AppSharer` refuses a stale versionCode), pairing, HANDOFF.md, a very long gotchas list (Robolectric vs Hilt app class, REPLACE-upsert cascades, UTC date pickers, recurrence anchored to absolute dates, snooze request codes, signing mismatch -> `INSTALL_FAILED_UPDATE_INCOMPATIBLE`).
* Real incidents to remember: Kotlin block comments nest (`/*` in a KDoc); unescaped apostrophe in strings.xml; KSP flake (`Expected start of the object`) = re-run; lint prints only a count (print the report file); emulator test command must not end with `|| echo`; first-run dialogs cover UI under test; sealed-class `when` exhaustiveness (grep before pushing).
* Kodesh-app (plain web app, not WebView-packaged): `CLAUDE.md` rules - verify every external API ref (Sefaria/Hebcal) with a probe and date-stamp it, graceful Hebrew fallbacks, keep `AGENT.md` current, SW cache list updated, domain content only from sources the owner confirms.
