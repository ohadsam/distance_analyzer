# Changelog

## 0.2.0
- **Design foundation (from the ChatGPT "Momentum" kit, `design/momentum/`)**: eight look packs (momentum, ocean, forest, sunset, violet, slate, mono, high-contrast), each light + dark, generated into `web/css/packs.css` and 54 UI icons into `web/js/iconData.js` by `npm run design`. A unit test re-checks WCAG contrast of every pack and that the generated files are current. Working name "Momentum" is the kit's, not the app's: the app name is still open.
- **Workout mode** (walk / run): GPS distance with accuracy and jump filtering, moving time, current + average pace, km splits (interpolated), kcal estimate, pause/resume, finish with confirmation, summary with a tile-less route drawing, history and detail, delete. One screen, three numbers, three buttons; **screen lock** that needs a press-and-hold; the screen stays awake; a workout in progress survives a reload (it waits paused, so the gap is not counted).
- **Smart rhythm coach (metronome)**: one tap turns it on. It listens to the footsteps with the motion sensor, stays silent for 20 s while it learns, and once the cadence has been steady for 8 s it starts clicking at that cadence (look-ahead scheduler on the Web Audio clock) with a calm pulse animation and a breathing guide (default in 3 steps, out 2; accent on the first beat of each cycle). It shows whether you are on rhythm / a little fast / a little slow, re-locks only after a clearly new steady cadence (16 s), goes silent again when you stop or pause, and has a by-hand rhythm (± buttons, default in Settings) when the phone has no motion sensor. Settings: breathing pattern, click volume, default rhythm.
- Android: `ACCESS_FINE/COARSE_LOCATION` (asked at first workout, granted to our own origin only via `onGeolocationPermissionsShowPrompt`), `NativeBridge.keepAwake(Boolean)`. Still no `INTERNET`.
- Tests: unit (geo/workout, cadence on synthetic accelerometer signals, breathing pattern, design tokens) and e2e with mocked GPS and a fake footstep sensor on a fake clock (learning silence, lock, pause, no-sensor fallback, lock screen, resume after reload, settings), axe at zero for every screen incl. workout + rhythm and three packs, 320 px.
- Verified: static checks, unit tests, e2e in Chromium. **Not verified here (needs a real phone / CI):** the Kotlin build, real GPS accuracy, real accelerometer cadence detection while running (thresholds are tuned on synthetic data), audio timing on a device, battery use. Known limit: tracking and the metronome run only while the screen is on and the app is in front (a foreground location service is the next step).

## 0.1.0
- Project skeleton: vanilla-JS PWA (`web/`, no build step, no runtime dependencies) + thin Android WebView shell (`android/`) that packages the same `web/` folder as assets.
- Hebrew (RTL, default) and English; light/dark; offline service worker; CSP `'self'` only.
- Pipeline copied from the sister project (morning_organizer): static + security checks, unit tests, Playwright e2e with axe-core, Android unit tests + lint + signed release APK, GitHub Release `distance-analyzer.apk` on `main`, PWA on GitHub Pages.
- Verified: static checks, unit tests, e2e. Not verified here: the Android build (CI only).
