## Two technical tiers (the app can use both)
TIER 1 - UI icons, drawn inline by the app from a whitelist: viewBox 0 0 24 24; ONLY these elements: g, path, circle, ellipse, rect, line, polyline, polygon; ONLY these attributes: d cx cy r rx ry x y x1 y1 x2 y2 width height points fill stroke stroke-width stroke-linecap stroke-linejoin transform opacity fill-rule clip-rule fill-opacity stroke-opacity **and, new, class and id** (values: letters, digits, hyphen only). No defs, gradients, filters, masks, clipPath, use, style, text, images, scripts, animation tags. Colour = currentColor only (the pack recolours it), depth comes from layers: the main shape at full opacity, a secondary layer at opacity .35, a highlight/detail layer at opacity .6, never more than 3 levels. Each icon <= 1.5 KB. Animated parts are separate <g> or shapes with class="m-<part>" (e.g. m-needle, m-leg-a, m-flame); everything else is static.
TIER 2 - EMBLEMS (large circular pictures, 96x96 and 200x200 viewBox): standalone SVG files, light and dark variant of each, shown through an img tag, so they MAY use defs, linearGradient/radialGradient (token colours only), and an internal <style> with @keyframes animation (transform and opacity only, transform-box: fill-box, explicit transform-origin) and an @media (prefers-reduced-motion: reduce) block that stops the animation on a complete still frame. No scripts, no external references, no fonts/images, hex colours, <= 20 KB each.

## Shared design rules for everything in this round
- Rounded and friendly: generous radii, no sharp corners except where meaning needs it; every glyph recognisable at 20 px; a consistent **signature**: a small round "trail dot" accent (one per icon where it fits) and a soft inner highlight, so the whole set reads as one family.
- 24 grid, 2 px safe margin, optical balance; same visual weight across the set; icons that mean direction (back, forward, undo, trend, play-forward) come as a pair `-start` / `-end` so the app can mirror them for Hebrew (RTL).
- Colour never the only signal. Contrast of emblems against their backgrounds >= 3:1 for the figure.
- Motion: gentle, never flashing, amplitude small, loops >= 800 ms (the characters excepted, see below), every animation is complete as a still first frame; the app has a "calm animations" switch and honours prefers-reduced-motion.
