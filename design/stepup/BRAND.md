# StepUp — Stage 1
Name in both locales: StepUp (Latin, case sensitive). No tagline. Brand mark is a rounded ascending two-step route with a start node and upward arrow. Never mirror the symbol. RTL lockup places symbol on right, but Latin lettering remains LTR. Custom path lettering, no fonts in SVG. Use mark alone below 96 px lockup width; use at least 20 px mark, 24 px preferred. Keep 8 units external clear space. Existing 64 grid retained; brand stroke 5.5, wordmark stroke 3.8; UI geometry unchanged. Use primary on background/surface, text for lettering, onPrimary on primary tile. Theme variants use original tokens, not new tokens. Default platform exports use Momentum light. iOS full bleed opaque; Android adaptive foreground/background separate, OS mask applied at runtime. Notification is white alpha mask for OS tint. No animation introduced. All new artwork is original hand-authored geometry, intended CC0; trademark availability not checked. Round 1 preview and generator are historical; do not run them over this delivery. To rebuild, place build_brand.py next to a baseline folder or the original archive one directory above (see script). Native platform catalogs and device testing are not included.
