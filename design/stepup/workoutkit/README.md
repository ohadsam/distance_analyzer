# StepUp — Workout Experience Visual Kit

Original additive assets for StepUp Little Trail / Momentum. Existing assets and token files were not edited.

## Technical contract

- Clean standalone SVG; no filters, scripts, text, fonts, images or external references.
- Illustrations have hex palette colours and light/dark variants; icons are intentionally theme-neutral `currentColor`.
- All SVGs are under 20 KB and have viewBox.
- Contact sheets are generated by CairoSVG from actual SVG files.
- Layering: greeting text sits on left 45% of banners; workout title in top 20% of share cards; metrics in lower quiet band.
- The chart plate is x=160, y=344, width=760, height=560, radius=36; transparent visual plate, no route included.
- The numerals are thick rounded vector strokes with no text/font; this is a deliberate deviation from strictly closed filled paths, though the visible result is a solid glyph.
- Countdown JSON uses 350 ms enter, 500 ms hold, 150 ms fade; static alternative included.
- The existing production palette was read from the previous celebration kit.

## Known limits

- Countdown digits use thick round stroke paths to form solid-looking numerals, rather than filled closed contours.
- CurrentColor icons require the app to set CSS color; no light/dark icon duplicate is needed.
- Contrast was measured for the designated quiet regions against the approved text token, not arbitrary colours or photos.
- No Android device integration tests, icon recognition studies or manual review at every native size were performed.
- The large rounded plate is softly blended but its exact pixelwise 6–8% luminance difference is not guaranteed at every point.
